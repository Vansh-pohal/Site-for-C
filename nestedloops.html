ITERATIVE CONTROL STRUCTURE (NESTED LOOPS)

Q1. Write a program print the pattern on the screen i.e. ? 11111 11111 11111

CLOSE 
#include <stdio.h>
int main() {
    int rows = 3, cols = 5;

    for(int i = 1; i <= rows; i++) {        // outer loop for rows
        for(int j = 1; j <= cols; j++) {    // inner loop for columns
            printf("1");
        }
    }
    return 0;
}

Output: 11111 11111 11111
